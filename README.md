# homeOS · Android

APK e note di rilascio ufficiali di homeOS. Il codice sorgente è mantenuto in una repository privata.

## Scaricare l’app

Apri [l’ultima release](https://github.com/0Daviduo0/homeOS-releases/releases/latest), leggi le novità e scarica l’APK allegato.

homeOS richiede Android 10 o successivo. Per aggiornare un’installazione esistente, installa l’APK mantenendo i dati dell’app. Android potrebbe chiedere di autorizzare l’installazione dal browser o dal gestore file.

## Contenuto delle release

Ogni versione include l’APK, le note in italiano su cosa è cambiato e il riferimento alla build. Questa repository non contiene credenziali né configurazioni private di compilazione.
